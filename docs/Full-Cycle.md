# سيناريو دورة كاملة لتجربة تمام

الهدف: تمشي على كل دور (مالك، موظف، عميل، متجر خارجي، مدير المنصة) في حوالي 30 دقيقة.
الخلفية: التاجر «متجر الأناقة» بيبيع بالدفع عند الاستلام، والعميل «هشام فؤاد».

## 0. قبل ما تبدأ
- الباك اند شغّال على `https://localhost:7265` بعد `Update-Database`.
- في `appsettings.Development.json`: `Cors:AllowedOrigins` فيها `http://localhost:4200`، وقسم `PlatformAdmin` موجود، و`PublicLinks:BaseUrl` = `http://localhost:4200`.
- الفرونت: `npx ng serve` على `http://localhost:4200`.
- افتح **نافذتين**: عادية (للتاجر) وخاصة Incognito (للعميل).

## 1. المالك يسجّل ويجهّز متجره (نافذة التاجر)
1. `/auth/register`: اسم النشاط «متجر الأناقة»، المالك «عبدالله إمام»، الدولة مصر، الهاتف `01012345678`، البريد `owner@tamam.test`، كلمة المرور `Owner1234`.
2. هتدخل الداشبورد (فاضية، تجربة 14 يوم).
3. **الإعدادات ← الخصوصية والشبكة**: وافق على مشاركة النتائج واحفظ. (قبل الحفظ طلب `consent` بيرجّع 404 وده طبيعي.)
4. **الإعدادات ← الموظفون ← إضافة موظف**: «سارة علي» `staff@tamam.test` / `Staff1234`.
5. **شركات الشحن**: أضف «بوسطة» (الهاتف `01011112222`).
6. **المنتجات**: أضف «حذاء رياضي» SKU `SH-43` بسعر 1500، و«قميص قطن» بسعر 860.

## 2. أول طلب كامل (نجاح)
1. **الطلبات ← طلب جديد**: المستلم «هشام فؤاد» `01012345678`، المدينة المنصورة، العنوان «15 شارع الجمهورية»، المنتجات: حذاء ×2 + قميص ×1، الشحن 40، الدفع عند الاستلام، شركة الشحن بوسطة.
2. افتح الطلب. **تقييم المخاطر**: عميل جديد فالمفروض الدرجة منخفضة. لاحظ سبب كل نقطة بالعربي.
3. **تأكيد الطلب مع العميل**: اضغط «نسخ الرابط» (أو «إرسال عبر واتساب» لفتح wa.me).
4. في نافذة **Incognito** افتح الرابط (`/c/<token>`) كأنك العميل، واضغط «أؤكد الطلب».
5. ارجع لنافذة التاجر: الحالة بقت «مؤكد»، وعداد الجرس زاد **لحظيًا** (SignalR) من غير Refresh.
6. **تغيير الحالة**: مؤكد ← تم الشحن (اكتب رقم تتبع) ← خرج للتسليم ← تم التسليم.
7. الداشبورد: عدّاد «تم التسليم» ونسبة التسليم اتحدّثوا.

## 3. طلب مرفوض ومعرفة المسؤول
1. أنشئ طلب تاني لنفس العميل بقيمة أعلى، وشحنه لحد «خرج للتسليم».
2. غيّر الحالة إلى **مرفوض**، وسجّل **محاولة تسليم** لو حبيت.
3. في كارت «الرفض والمسؤولية»: **بلّغ عن الرفض** واختر سببًا مثل «غيّر رأيه» ← المسؤول **العميل**.
4. انسخ **رابط استبيان الرفض** (`/s/<token>`) وافتحه في Incognito كالعميل، واختر سببًا مختلفًا (مثلًا مشكلة في الشحن) ← هيحصل **نزاع** لأن الإجابتين اتعارضوا.
5. عدّل **الخسارة** (شحن الذهاب والرجوع) وشوف الإجمالي.

## 4. العميل الخطر يظهر في الطلب الثالث
1. أنشئ طلب جديد لنفس رقم هشام.
2. تقييم المخاطر هيطلع **أعلى** مع أسباب مكتوبة («رفض طلبات سابقة عندك»...) وتوصية.
3. جرّب قرار التاجر: «سأتابع التوصية / سأتجاهلها / سأفعل العكس». القرار بيتسجّل للتحسين.

## 5. ربط المتجر عبر API (متجر خارجي)
هدف الربط: متجر Shopify أو موقعك الخاص يبعت كل طلب جديد تلقائيًا لتمام، فيرجع بدرجة المخاطر ورابط التأكيد بدون إدخال يدوي.
1. **الإعدادات ← ربط المتجر (API) ← توليد مفتاح**، وانسخه **فورًا** (بيظهر مرة واحدة).
2. من الطرفية (PowerShell أو bash، `-k` عشان شهادة التطوير):
```bash
curl -k -X POST https://localhost:7265/api/integrations/orders \
  -H "X-Api-Key: tmk_XXXXXXXX" -H "Content-Type: application/json" \
  -d '{
    "orderNo": "SHOP-5001",
    "recipientName": "منى أحمد",
    "recipientPhone": "01123456789",
    "city": "القاهرة",
    "addressLine": "10 شارع التحرير، الدقي",
    "shippingFee": 40,
    "paymentMethod": 1,
    "items": [{ "productName": "حذاء رياضي", "quantity": 1, "unitPrice": 1500 }]
  }'
```
3. الرد فيه `riskScore` و`confirmationLink` و`whatsAppUrl`. الطلب ظهر في **الطلبات** بمصدر API.
4. كرر نفس الأمر: هيرجع `alreadyExisted: true` ومفيش طلب مكرر.
5. `GET /api/integrations/orders/SHOP-5001` بنفس الـ header يرجّع الحالة الحالية.

## 6. الاستيراد بالجملة
**الطلبات ← استيراد**: نزّل القالب CSV، أضف صفين، ارفعه واختر النوع «عادي»، وشوف ملخص النجاح والأخطاء.

## 7. الموظف (نافذة ثالثة أو بعد تسجيل الخروج)
ادخل بـ `staff@tamam.test`: بيشتغل على الطلبات والعملاء، بس مفيش إدارة الاشتراك والإعدادات الحساسة.

## 8. الاشتراك والفواتير
**الاشتراك والفواتير**: شوف الاستهلاك، وغيّر الخطة إلى «الدفع حسب الاستخدام» (من غير دفع أونلاين حاليًا).

## 9. العميل يطلب حذف بياناته ومدير المنصة يعالجه
1. في صفحة تأكيد الطلب `/c/<token>` اضغط «طلب حذف بياناتي».
2. سجّل خروج، وادخل بحساب المدير (البريد والباسورد من قسم `PlatformAdmin`) ← `/admin`.
3. **طلبات البيانات**: عالج الطلب. جرّب كمان: نظرة عامة، التجار (تغيير الحالة والخطة)، قواعد المخاطر (تعديل النقاط)، سجل المراجعة.

## 10. المراجعة
**الإعدادات ← سجل التغييرات**: كل خطوة فوق ظاهرة بالمستخدم والوقت والتفاصيل.
